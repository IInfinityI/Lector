## Getting Started
To build the place from scratch, use:

Включите доступ к API:

File → Game Settings → Security

Проверьте "Enable Studio Access to API Services"


```bash
rojo build -o "DataManager.rbxlx"
```

Next, open `DataManager.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
