# Инструкция по настройке Rojo для синхронизации с Roblox Studio

## 1. Установка расширения в VS Code
1. Откройте **Visual Studio Code**
2. Перейдите в раздел расширений (Ctrl+Shift+X)
3. Найдите и установите расширение **"Rojo - Roblox Studio Sync"**

## 2. Настройка проекта
1. Откройте папку с проектом (например: `projectR\src\assets\AssetLoader`)
2. В правом нижнем углу найдите иконку Rojo и нажмите на неё
3. В появившемся меню выберите **"Install Rojo now"** и дождитесь завершения установки

## 3. Установка плагина для Roblox Studio
1. В том же меню Rojo выберите **"Install Roblox Studio Plugin"**
2. Откройте проект в Roblox Studio (новый или существующий)
3. Перейдите во вкладку **"Плагины"** и проверьте наличие Rojo

## 4. Запуск синхронизации
1. В VS Code запустите сервер в меню Rojo (зелёная кнопка "Start"`default.project.json`)
2. В Roblox Studio откройте плагин Rojo
3. Нажмите кнопку **"Connect"**
4. Подтвердите применение изменений

> Примечание: Для корректной работы убедитесь, что:
> - У вас установлена актуальная версия Roblox Studio
> - Файл `default.project.json` правильно настроен
