# Lector — Интеллектуальная система записи лекций

## 📁 Структура проекта

```
app/src/main/java/com/example/lector/
├── models/                     # Модели данных (Data Layer)
│   ├── ContentBlock.java       # Базовый класс для всех блоков контента
│   ├── BlockType.java          # Перечисление типов блоков
│   ├── TextBlock.java          # Блок текста транскрибации
│   ├── MathBlock.java          # Математическое выражение
│   ├── TableBlock.java         # Таблица
│   ├── ImageBlock.java         # Изображение/рисунок
│   ├── GraphBlock.java         # График
│   ├── HeadingBlock.java       # Заголовки и абзацы
│   └── Lecture.java            # Модель всей лекции
├── services/                   # Бизнес-логика (Logic Layer)
│   ├── AudioRecorderService.java      # Запись аудио
│   ├── TranscriptionService.java      # Распознавание речи
│   ├── SpeakerDiarizationService.java # Определение спикеров
│   └── ContentAnalyzerService.java    # Анализ контента
├── utils/                      # Вспомогательные утилиты
│   └── NumberUtils.java        # Парсинг русских чисел
├── screens/                    # UI экраны (в разработке)
├── widgets/                    # UI компоненты (в разработке)
├── MainActivity.java           # Главная активность
├── FirstFragment.java          # Фрагмент 1
└── SecondFragment.java         # Фрагмент 2
```

## ✅ Реализованный функционал

### Модели данных (Models)
- **ContentBlock** - Абстрактный базовый класс для всех типов контента
  - Уникальный ID, временная метка, информация о спикере
  - Поддержка верификации и предупреждений
  - Экспорт в Markdown

- **TextBlock** - Блок текста с поддержкой:
  - Автоматического определения языка (RU/EN/mixed)
  - Таймкодов для каждого слова (для синхронизации с аудио)
  - Пометки неточностей (**текст**)

- **MathBlock** - Математические выражения:
  - Парсинг устных формул ("два плюс три" → "2+3")
  - Генерация LaTeX представления
  - Поддержка степеней, корней, дробей

- **TableBlock** - Интерактивные таблицы:
  - Динамическое добавление/удаление строк и колонок
  - Экспорт в Markdown и CSV
  - Поддержка заголовков

- **ImageBlock** - Изображения:
  - Фотографии с камеры
  - Нарисованные схемы (хранение точек)
  - Подписи к изображениям

- **GraphBlock** - Графики:
  - Линейные и столбчатые графики
  - Точки данных с подписями
  - Экспорт данных в текстовом виде

- **HeadingBlock** - Структура текста:
  - Заголовки уровней H1-H6
  - Подзаголовки
  - Абзацы с форматированием (bold, italic)

- **Lecture** - Основная модель:
  - Коллекция всех блоков контента
  - Метаданные (предмет, дата, длительность)
  - Список спикеров
  - Экспорт в Markdown
  - Авто-именование файлов

### Сервисы (Services)

- **AudioRecorderService** - Запись аудио:
  - Формат M4A (AAC), 128 kbps, 44.1 kHz
  - Авто-именование: `Предмет_Дата_Время.m4a`
  - Сохранение в локальную директорию
  - Start/Stop/Cancel операции

- **TranscriptionService** - Распознавание речи:
  - Потоковая транскрибация через SpeechRecognizer
  - Поддержка смешанного RU/EN языка
  - Частичные результаты (real-time)
  - Обработка ошибок и перезапуск

- **SpeakerDiarizationService** - Определение спикеров:
  - Эвристический анализ паттернов речи
  - Разделение на "Преподаватель"/"Студент"
  - Отслеживание сегментов речи
  - Цветовое кодирование спикеров

- **ContentAnalyzerService** - Анализ контента:
  - Распознавание команд форматирования
  - Создание заголовков по команде
  - Детекция математических выражений
  - Разбиение текста на предложения

### Утилиты (Utils)

- **NumberUtils** - Работа с числами:
  - Преобразование русских числительных в цифры
  - Поддержка составных чисел ("двадцать один" → 21)
  - Проверка наличия чисел в тексте

## 🔧 Архитектура

Приложение следует принципам **Clean Architecture**:

1. **UI Layer** (screens/, widgets/)
   - Отображение контента
   - Пользовательские взаимодействия
   - Анимации и переходы

2. **Logic Layer** (services/)
   - Бизнес-логика
   - Обработка аудио и текста
   - Анализ контента

3. **Data Layer** (models/)
   - Структуры данных
   - Сериализация
   - Экспорт форматов

4. **Utils**
   - Вспомогательные функции
   - Парсинг и конвертация

## 📝 Хранение данных

- **Аудиофайлы**: Локальная файловая система (`/storage/emulated/0/Android/data/com.example.lector/files/recordings/`)
- **Конспекты**: SQLite (планируется) + сериализация моделей
- **Изображения**: Локальная файловая система
